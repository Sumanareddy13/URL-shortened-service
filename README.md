# URL-shortened-service
This is a Spring Boot application that provides a URL shortener service using MongoDB as the database. It allows users to shorten long URLs and retrieve the original URLs by using a short key.
The application exposes REST APIs that can be tested using Postman or any other API testing tool.

# Features
✅ Shorten a given long URL
✅ Retrieve the original long URL using the short URL key
✅ Redirect users from the short URL to the original URL
✅ Store and retrieve URL mappings in MongoDB
✅ Fully tested using JUnit and Mockito

# Technologies Used
Spring Boot (Java), Spring Web, Spring Data MongoDB, MongoDB, JUnit 5 & Mockito (for testing), Postman (for API testing)
